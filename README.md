# Listening Before Birth

Static browser-based research presentation for Najla Saad Almotiri.

## Run locally

From this folder:

```bash
python3 -m http.server 8000
```

Then open:

```text
http://localhost:8000
```

If that port is already in use, choose another port such as `8001` and open the matching address.

## Controls

- Previous / Next buttons or left / right arrow keys
- `F` or the Fullscreen button for presentation mode
- `O` or Overview for slide navigation
- `R` or Rehearse for presenter notes and timer
- `S` or Spotlight for a pointer-style discussion spotlight
- Click original figures to enlarge them
- Use the browser print dialog to export one slide per page

## GitHub Pages publishing

Upload the `listening-before-birth-presentation` folder to the repository. In GitHub Pages settings, publish from the branch and folder that contains this directory. The presentation uses relative paths, so it works under a repository subdirectory.
